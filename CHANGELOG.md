# История изменений

## 16.5 — 31 июля 2026

### Новое и улучшения

- Добавлена и обновлена русская локализация интерфейса.
- Добавлено автодополнение названий игр в настройках приоритетов и исключений.
- Поиск игр выполняется по каталогу Twitch, а не только по уже загруженному локальному списку.
- Поиск запускается с задержкой после ввода текста, поэтому можно спокойно напечатать полное название игры.
- Список вариантов не закрывается после каждой введённой буквы и корректно обновляется для актуального запроса.
- В интерфейсе авторизации оставлена только одна доступная кнопка: «Войти» или «Выйти».
- Кнопка авторизации выровнена по центру главного экрана.
- Выход перенесён из раздела «Помощь» на главную страницу.
- При выходе Twitch OAuth-токен отзывается, cookies очищаются, а приложение запускает авторизацию заново.
- Обновлены название приложения, имя сборки и документация для форка catbardi.

### Исправления

- Исправлено устаревание данных просмотра канала после изменения параметров трансляции.
- Добавлено автоматическое обновление Spade-адреса при ответах Twitch 404/410.
- Повышена надёжность сохранения настроек и кэша: добавлены временный файл, резервная копия и восстановление после повреждения JSON.
- Исправлен путь переименованного пакета macOS в GitHub Actions.
- Исправлено поведение выбора игры при наборе текста и точной фильтрации результатов.

### Проверка

- Пройдены автоматические тесты проекта и тесты автодополнения.
- Выполнена проверка синтаксиса Python.
- Выполнена сборка Windows через PyInstaller.
