# Changelog

Изменения сборки [catbardi/TwitchDropsMiner](https://github.com/catbardi/TwitchDropsMiner) относительно форка и собственных доработок.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [16.6] — 2026-11-04

### Добавлено

- Горячие патчи GQL-хэшей и User-Agent через `gql_overrides.json` (загрузка с GitHub + кэш на диске, без пересборки exe).
- Вкладка **Инвентарь → Все активные кампании**: все текущие активные кампании Twitch без фильтров приоритета/исключений.
- Понятные сообщения при `PersistedQueryNotFound` (какая операция устарела и куда смотреть патч).
- CI и nightly-проверка актуальности ключевых GQL-хэшей (`scripts/check_gql_hashes.py`).
- Ссылки в Help на стабильные релизы и файл overrides.

### Синхронизация

- Подтянут upstream [DevilXD/TwitchDropsMiner](https://github.com/DevilXD/TwitchDropsMiner) (браузерный логин, новый mining через playlist HEAD, обновления GQL/UA).

## [16.5] — 2026-07-30

### Добавлено

- Автодополнение названий игр в списках приоритета и исключений.
- Усиление безопасности сетевых запросов, журналов и обработки изображений.
- Брендинг приложения как сборки catbardi.

### Исправлено

- Надёжность просмотра и сохранения настроек.
- Улучшена русская локализация.

## Ранее

Базовые доработки форка до выделенных тегов:

- полная правка русской локализации;
- исправление устаревания времени в событиях просмотра;
- автоматическое обновление недействительного адреса Spade;
- безопасное сохранение настроек/кэша и восстановление из backup при битом JSON;
- автотесты для ключевых исправлений.
